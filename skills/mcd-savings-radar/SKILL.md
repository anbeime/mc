# 麦麦省钱雷达

把麦当劳送给用户的优惠，真正变成用户口袋里的钱。

## 何时使用

- "我的麦当劳券快过期了吗？"
- "帮我领一下麦当劳的券"
- "今晚想吃巨无霸，怎么点最省？"
- "麦当劳最近有什么活动？"
- "我的麦当劳积分要过期了吗？"

## 前置条件

需要麦当劳中国 MCP Token（https://open.mcd.cn/mcp → 登录 → 控制台 → 激活），
并已配置环境变量：

```bash
export MCD_MCP_TOKEN="<你的 Token>"
```

项目根目录：`<本 Skill 所在仓库>`。所有命令都在该目录下执行。

## 工作流

### 步骤 1 · 先探一下环境

```bash
python -m mcd_radar tools
```

- 如果返回 33 个 Tool → Token 正常，继续。
- 如果报"鉴权失败" → 提示用户重新申请 Token，**终止后续步骤**，不要重试。
- 如果未配置 Token → 提示用户 `export MCD_MCP_TOKEN=...`，**不要伪造数据**。

### 步骤 2 · 按用户意图选命令

| 用户意图 | 执行命令 |
|---|---|
| 只想领券 | `python -m mcd_radar bind` |
| 想看券包 / 到期情况 | `python -m mcd_radar coupons` |
| 问"怎么点最省" | `python -m mcd_radar deals --budget <预算> --want <想吃的>` |
| 问"附近有什么活动" | `python -m mcd_radar --address "<城市/商圈>"` |
| 想一次性看全 | `python -m mcd_radar --address "<地址>" --bind` |
| 要一份好看的报告 | 追加 `--html report.html`，然后打开该文件 |

### 步骤 3 · 把结果讲成人话

不要复述 JSON。按下面的优先级组织回答：

1. **先说最紧急的** —— 有券几天内过期 / 有积分即将清零，直接点出来。
2. **再说最省的** —— 给出 1–2 个具体组合：吃什么、用哪张券、实付多少、省了多少。
   - 如果券带适用范围（如"限：外送订单"），**必须一并说明**，避免用户用错场景。
3. **最后给建议** —— 例如"这周三积分翻倍，可以等两天再下单"。
4. 涉及金额的地方保留原始数值，不要四舍五入成模糊表述。

### 步骤 4 · 需要反复提醒时，建议设置自动化

如果用户希望**定期**知道券要过期了，建议他创建一个定时任务（如每天 09:00 执行
`python -m mcd_radar coupons` 并把结果播报出来），而不是每次手动询问。

## 命令参考

```bash
python -m mcd_radar [--address <地址>] [--store <门店码>] [--budget <金额>]
                    [--want <关键词,逗号分隔>] [--bind] [--html <路径>] [--json]
python -m mcd_radar bind       # 一键领券
python -m mcd_radar coupons    # 券包盘点 + 到期预警
python -m mcd_radar deals      # 最省组合推荐
python -m mcd_radar tools      # 列出 MCP 全部 Tool
```

## 边界与红线

- **只读**：本 Skill **绝不**自动调用下单类接口（`create-order` / `mall-create-order` /
  `party-order-create`）。下单必须由用户自己确认后操作。
- **不猜**：拿不到数据就说拿不到，不要编造券、门店、价格或活动。
- **不泄露**：任何情况下都不得把 MCP Token 写进文件、日志或回复正文。
- **口径**：餐品价格与券规则以麦当劳官方实时结果为准，回答时不要给出绝对化承诺。
- **非官方**：这是参赛作品，非麦当劳官方产品；涉及营养/健康问题时应提示这仅供参考。
